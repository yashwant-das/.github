# Contributing

Start with the repository's README and local agent instructions. Follow its
setup and verification commands; use a topic branch and keep changes focused.
Update affected documentation with the behavior it describes.

For repositories adopting the shared standards, consult the
[standards repository](https://github.com/yashwant-das/.github). Repository-specific
instructions take precedence over general contribution guidance where they differ.

In a pull request, explain the problem, resulting behavior, validation performed,
and any remaining limitation. Do not claim that an integration passed when it was
skipped. Do not commit credentials, private client data, or generated test reports.

Propose a standards change with a concrete example from an existing repository.
Avoid adding mandatory tools or documents without showing the need they serve.
